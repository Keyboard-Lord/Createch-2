Burnt - global block-mapping datapacks
======================================
A ready-to-edit starter pack ("Burnt Block Mappings") is placed in this folder
automatically on first run - open its files under data/burnt/tags/block/ and add
your blocks. You can also drop your own mapping datapacks here (a folder or a .zip,
the same kind you would put in <world>/datapacks/).
Everything in this folder applies to EVERY world automatically - no per-save copying -
and is always enabled. After adding or editing a pack, run /reload in-game (or rejoin
the world) to pick up the change.

When Burnt ships an updated starter pack it replaces this one only if you have not
edited it. If you have, yours is kept and a note appears in the log - delete the folder
to take the new one. A pack from an older Burnt version is moved to ../mappings_backup
first, so nothing is ever lost.
