# Maintenance and Operations

Maintenance is an operating discipline, not a random timer. Createch does not silently delete machine parts. Instead, the recovery path asks the factory to keep the components that make a causal repair possible.

Maintain a labeled, disconnected store of tier-appropriate GT motors, pumps, sensors, robot arms, Electro Energetics fuses and breakers, AE2 network tools, filters, seals, and machine-specific parts. A spare still locked by research is not an emergency spare.

Use this restart order:

1. isolate power, pressure, fuel, fluids, and automated requests;
2. diagnose the failed subsystem with gauges, local indicators, and known-good test articles;
3. replace the smallest causal part and clear blocked inputs or outputs;
4. start generation and protection, then utilities, then processing, then logistics and requested production;
5. prove one normal batch and replenish the spare store.

The Age 10 preparedness quest makes HV motors, pumps, sensors, fuses, and an AE2 network tool part of the recovery economy. Later tiers repeat the same institution with higher-grade components.
