# Enrichissement de précision

Chez Digital Âge, **CHE-05B — Enrichissement de précision** ouvre un pilote limité : tétraèdrite. Ce n'est pas un commutateur universel de Mekanism 5×.

1. Macéré TFC tétraèdrite dans MI. Mauvais, normal et riche alimentation récupérer plus de poudre que la querne; poussière de soufre est le flux latéral utile.
2. Dissoudre dix poudres de tétraédrite avec de l'acide sulfurique Mékanisme dans du lisier de cuivre sale.
3. Lavez le lisier avec la laveuse chimique.
4. Cristallisez le flux propre.
5. Utilisez le cristal natif du Mékanisme → shard → clump → poussière sale → séquence de poussière, puis retournez le cuivre à l'économie normale de la métallurgie.

Les TFC Les amorces de minerais/de minerais bruts du Mékanisme natif dans sa chaîne de cuivre à forte multiplication sont fermées; les stades chimiques internes demeurent intacts.

Récupéré `tfmg:sulfur_dust` alimente la chimie sulfurique-acide installée. installation stop, la beneficiation doit être remarquée.
