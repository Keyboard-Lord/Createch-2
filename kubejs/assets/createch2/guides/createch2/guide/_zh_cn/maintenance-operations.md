# 维修和业务

维护是操作性学科,不是随机计时器。 Createch 不默默删除机器部件。 相反, 恢复路径会询问 工厂 以保留造成因果关系的组件 修复 可能,也许。

维持一个贴标签、断开的适合级别存储 GT 发动机、泵、传感器、机器人臂、 电力电网 引信和断路器, AE2 网络工具、过滤器、封条和机器专用部件。仍然被研究锁定的备用件不是应急备用件。

使用这个 重新启动 顺序 :

1. 隔离 动力、压力、燃料、液体和自动化请求;
2. 以测量仪、局部指标和已知的好试验文章来诊断失败的子系统;
3. 替换最小的因果部分,并清除被封锁的投入或产出;
4. 开始生产和保护,然后是公用事业,然后是加工,然后是物流和要求生产;
5. 证明一个正常批次,并补充备用商店。

电话 时代 10次准备探险使HV发动机、泵、传感器、引信和一台 AE2 网络工具是复苏经济的一部分。以后的层次重复同一机构,其组件等级较高。
