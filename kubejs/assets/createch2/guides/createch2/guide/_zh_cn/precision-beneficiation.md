# 精密选矿

数字化 时代, **CHE-05B — 精密选矿** 打开一个有边框的飞行员: 四面体。 这不是通用的 Mekanism 5x 开关 。

1. 迈斯特级 TFC 四面体内 MI,贫乏,正常,丰富的饲料比克恩恢复的粉末更多;硫灰是有用的侧流.
2. 用麦坎尼主义硫酸溶解十种四面体粉末,制成脏铜浆.
3. 用化学瓦舍洗浆.
4. 结晶清净溪流.
5. 使用原生的梅卡尼主义晶体 → 硬的 → 粘土 → 脏的尘埃 → 尘埃序列,然后将铜还原为正常的冶金经济.

电话 TFC quern和普通冶金随着低基础设施的倒塌而仍然可用. 原始的Mekanism矿石/草速进入其高倍增铜链的捷径被关闭;内部化学阶段仍然完好无损.

已恢复 `tfmg:sulfur_dust` 用于供养已安装的硫酸化学。如果酸 工厂设施 停止, 注意注意。

运行此 工业区 保护对象 电力电网 进程总线。设备连接器是 FE 交接; 调制或通用 FE 电缆不是另一个分配当局。
