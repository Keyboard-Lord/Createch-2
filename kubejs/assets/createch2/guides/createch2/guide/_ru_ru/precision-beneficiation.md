# Прецизионное обогащение

В цифровом Эпоха, **CHE-05B — Прецизионное обогащение** открывается один ограниченный пилот: тетраэдрит. Это не универсальный переключатель 5× Меканизма.

1. Сортированный мацерат TFC тетраэдрит в MI Бедные, нормальные и богатые корма извлекают больше порошка, чем кукуруза; серная пыль является полезным побочным потоком.
2. Растворите десять тетраэдритов порошка с серной кислотой меканизма в грязную медную суспензию.
3. Вымойте суспензию с помощью химического стирального устройства.
4. Кристаллизировать чистый поток.
5. Используйте родной кристалл меканизма → осколки → комок → грязная пыль → последовательность пыли, затем возвращайте медь в нормальную металлургическую экономику.
